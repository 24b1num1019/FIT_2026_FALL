# Гурван үеийн түүх

A responsive single-page family heritage archive built with HTML, CSS, and JavaScript.

## Customize
- Replace bracketed placeholders in `index.html` with family biographies.
- Add photos in `assets/images/` using the exact filenames referenced by the HTML.
- After publishing to GitHub Pages, generate a QR code linking to the public site and replace the `#qr-slot` placeholder.

## Run
Open `index.html` in a browser. No build step required.
